# HIA Documentation System — CSS Documentation Tool Package API

Native API reference for the eight CSS documentation tool packages, generated by HIA Documentation System.

## Contents

The reference covers public bindings from `@hia-doc/css-doc-adapter`, `@hia-doc/css-doc-extractor`, `@hia-doc/css-doc-source-map`, `@hia-doc/css-parser`, `@hia-doc/cssdoc-producer`, `@hia-doc/cssdoc-runner`, `@hia-doc/cssdoc-spec` and `@hia-doc/design-token-bridge`. It includes original API documentation, current/legacy configuration and extraction schemas, static declaration data, source maps and authorized complete sources.

## Publication

`snapshot.json` pins the source commit, publication identity, production registry and complete archive digests. GitHub Actions verifies every archived file, native fields, scoped public bindings, maps and full-source downloads before deployment. Generated content is supplied through a fixed release archive.

To update the site, build the source repository, validate both locales, publish the fixed archive and report, and update the snapshot. Version and language targets select this CSS partition.
